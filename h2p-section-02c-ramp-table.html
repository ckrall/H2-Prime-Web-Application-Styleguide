Section 02C — Ramp Table

A plain hex-and-OKLCH data table for every ramp in the system — a secondary view alongside Section 2B's strip-and-contrast-ratio reference. 2B is the detailed reference for choosing a stop against a real surface; this page is the fast lookup when what's needed is just "what's the value at step 600." Same 9 ramps, same 12 stops, no token assignments or contrast math repeated here — see 2B for those.

Reading this table
Each row is one of the 12 fixed stops (25 · 50 · 100 · 200 · 300 · 400 · 500 · 600 · 700 · 800 · 900 · 950). The anchor stop — the exact hex a ramp was built around — is outlined and marked with ●. OKLCH values are shown as L% C H°. For token assignments (which stop backs which semantic role) and contrast ratios against the light-mode page surface, see Section 2B.
