Section 02B — Color Ramp Reference

Full 12-stop reference for all 11 H2 Prime color ramps. Every stop shows hex value, OKLCH coordinates, and contrast ratio against the primary light-mode application surface (Neutral 25, #FBFCFD). Anchor stops are marked with a yellow ring. Token assignments called out per ramp.

Reading this reference

Each ramp cell shows: stop number · hex value · approximate OKLCH coordinates (L% C H°) · contrast ratio vs Neutral 25 surface. AAA = ≥7:1 · AA = ≥4.5:1 · AA-L = ≥3:1 large text only · — = below 3:1. Anchor stops are marked with a yellow border ring. Hover any swatch to see it expand.

The Violet ramp is identical in hue to the Help utility ramp — they are the same 12-stop ramp referenced by two different semantic token sets. Admin interactive tokens (--theme-accent-*) drive buttons and nav. Help utility tokens (--feedback-help-*) drive passive feedback surfaces. Never confuse or cross-reference these two token sets.
